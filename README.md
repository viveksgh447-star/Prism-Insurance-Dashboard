# Prism-Insurance-Dashboard

🎯 Data Analyst Internship Project | Insurance Dashboard (Power BI)
I’m excited to share one of my internship-level projects where I built an interactive Insurance Analysis Dashboard for Prism Insurance Pvt. Ltd. 📊
This project simulates a real-world business scenario where a data analyst supports decision-making using data-driven insights.
🔍 Project Overview:
Analyzed insurance data to uncover trends in premiums, claims, and customer behavior.
📊 Key Metrics:
• 💰 Premium Amount: 5.98M
• 🛡️ Coverage Amount: 600.55M
• 📉 Claim Amount: 16.91M
📈 Dashboard Insights:
• Travel policies generate the highest premium revenue
• ~58% of policies are active
• Adults contribute the highest claim amounts
• Clear visibility into claim status (Rejected, Settled, Pending)
• Policy-type level performance tracking
🛠️ Skills Demonstrated:
• Data Cleaning & Transformation
• Data Modeling
• DAX Calculations
• Dashboard Design & Storytelling
💻 Tools Used:
Power BI | Excel
